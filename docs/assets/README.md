# README artwork provenance

- `mac.png` and `mac-light.png`: bitmap captures of Vibechar's actual native AppKit
  interface, from `AppDelegate.syntaxSmokeTest`, with synthetic JSON demo text.
- `do-the-rest.png`: native Do the Rest preview captured by `--smoke-examples`,
  with synthetic names/IDs and a local test provider response. The preview is real;
  this capture is not a claim about a live model's inference quality.
- Brand icon: the selected generated Graphite master and exact prompts live under
  `apps/macos/Artwork/`. No user clipboard, private scratch content or API key is
  used in documentation captures.
