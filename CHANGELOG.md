# Changelog

Notable changes to Vibechar. Versions follow Semantic Versioning; release notes
are generated from Conventional Commits. Earlier `build-*` archives predate versioned releases.

## [1.0.0] — 2026-11-17

### Added

- Native Apple Silicon Mac editor and a terminal client sharing one Rust editing engine.
- Scratch tabs, file editing, automatic ordinary-tab recovery and private tabs.
- Smart detection and highlighting for 186 syntax grammars.
- Multiple selections, regex find/replace, local text tools, line numbers and text statistics.
- Shared indentation, wrapping and adaptive handling of large text.
- Secret Drop: temporary local access for agents without pasting secrets into chat.
- Mac OpenAI settings, reviewable selection rewrites and protected fragments.
- Do the Rest: learn a structural rule from one example, preview it locally and save offline recipes.
- The unified `vc` launcher, one-curl installer and menu-based PATH setup.
- Versioned releases, an automated changelog and signed in-app Mac updates.

### Distribution

- Developer ID signing, Apple notarization and checksum-verified downloads.
- Mac GUI, terminal and launcher update together in one app bundle.
- Portable Linux x86_64 terminal client.
